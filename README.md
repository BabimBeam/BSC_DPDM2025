## รายละเอียดบทเรียน
### 📌 Chapter 1 — Introduction to Data Mining 
#### 💡 Data Mining คืออะไร?
Data Mining คือกระบวนการค้นหาความรู้ที่มีคุณค่าจากข้อมูลจำนวนมหาศาลมีรากฐานจากหลายศาสตร์สำคัญ และถูกใช้อย่างแพร่หลายทั้งในธุรกิจ วิทยาศาสตร์ และระบบออนไลน์ ความท้าทายหลักคือปริมาณ, ความซับซ้อนของข้อมูล และความเป็นส่วนตัวของผู้ใช้ เรียกอีกชื่อหนึ่งว่า **Knowledge Discovery in Databases (KDD)**
  - เอกสาร: [บทที่ 1 Introduction to Data Mining](01Intro.pdf)

### 📊 Chapter 2 — Getting to Know Your Data  
เรียนเกี่ยวกับการทำความเข้าใจโครงสร้างข้อมูล สถิติเบื้องต้น การมองข้อมูลผ่าน Visualization และการวัดความเหมือน/ต่างของข้อมูล เพื่อเตรียมพร้อมก่อนทำ Data Mining.
  - เอกสาร: [บทที่ 2 Getting to Know Your Data](02Data.pdf)

### 💻 บทที่ 3 การเตรียมข้อมูลเบื้องต้น (Data Preprocessing)
เรียนเกี่ยวกับแนวคิด วิธีการ และขั้นตอนในการทำให้ข้อมูลมีคุณภาพก่อนเข้าสู่กระบวนการ Data Mining โดยครอบคลุมเรื่องการล้างข้อมูล (missing, noise, outlier), การรวมข้อมูลจากหลายแหล่ง, การลดขนาดข้อมูล (data reduction), การเปลี่ยนรูปแบบข้อมูล (transformation) รวมถึงการทำ dimensionality reduction
  - เอกสาร: [บทที่ 3 Data Preprocessing](03Preprocessing.pdf)
